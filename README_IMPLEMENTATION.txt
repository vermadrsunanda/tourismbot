🎯 AGENT CAPABILITIES

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

5 INTEGRATED TOOLS:

1️⃣ WEATHER Tool
   • Get real-time weather conditions
   • Parameters: city (string)
   • Returns: Temperature, conditions, humidity, wind speed
   • Example: "What's the weather in Paris?"

2️⃣ FLIGHTS Tool
   • Search for flights between cities
   • Parameters: from_city, to_city (strings)
   • Returns: Airlines, prices, departure/arrival times
   • Example: "Find flights from NYC to Tokyo"

3️⃣ ATTRACTIONS Tool
   • Get popular attractions for a city
   • Parameters: city (string)
   • Returns: List of major attractions
   • Example: "Show me attractions in Rome"

4️⃣ TRAVEL_TIPS Tool
   • Get travel advice and tips
   • Parameters: destination (string)
   • Returns: Travel advice specific to destination
   • Example: "Give me travel tips for Barcelona"

5️⃣ CHAT Tool
   • General conversation
   • Parameters: N/A
   • Returns: Natural language responses
   • Example: "Tell me about travel"

AGENTIC LOOP PROCESS:
├─ Receive user query
├─ Iteration 1: LLM analyzes and calls Tool A
├─ Iteration 2: LLM processes Tool A result, calls Tool B
├─ Iteration 3: LLM processes results, calls Tool C
├─ ... (up to 5 iterations)
├─ Final: Compile all tool results into response
└─ Return: Answer + tools used + iteration count
