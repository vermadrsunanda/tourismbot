🆘 TROUBLESHOOTING

Problem: "Command 'git' not found"
Solution: Install Git from https://git-scm.com

Problem: Deployment fails with "ModuleNotFoundError"
Solution: Run "pip freeze > requirements.txt" and push again

Problem: API key not working
Solution: Check secret is named MISTRAL_API_KEY (exact spelling)
         Wait 30 seconds after saving secret for app to restart

Problem: Voice not working
Solution: Try Chrome or Firefox
         Allow microphone permissions in browser

See STREAMLIT_CHECKLIST.md for more troubleshooting
