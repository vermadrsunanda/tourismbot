🚀 HOW TO USE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣  FLASK WEB VERSION (Port 5000)
    $ python -m src.app
    → http://127.0.0.1:5000

2️⃣  STREAMLIT VERSION (Port 8501) ⭐ RECOMMENDED
    $ streamlit run streamlit_app.py
    → Opens automatically in browser

3️⃣  TRY THESE COMMANDS
    • "Tell me about Paris"         → Get chat response + weather + attractions
    • "Show flights to Tokyo"       → See flight options
    • [Click 🎤 Voice button]       → Speak instead of typing
    • Listen to AI responses        → Auto voice playback

🌐 DEPLOY TO CLOUD (3 OPTIONS)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

⭐ OPTION 1: STREAMLIT CLOUD (EASIEST)
   ✓ Free tier
   ✓ 2-minute setup
   ✓ No DevOps needed
   
   Steps:
   1. Push code to GitHub
   2. Go to https://share.streamlit.io
   3. Click "New app"
   4. Select your repo + streamlit_app.py
   5. Add secret: MISTRAL_API_KEY=your_key
   6. Deploy!

⭐ OPTION 2: VERCEL (BEST PERFORMANCE)
   ✓ Best performance
   ✓ Generous free tier (100 GB/month)
   ✓ Auto-scaling
   
   Steps:
   1. npm install -g vercel
   2. vercel --prod
   3. Set env vars in dashboard

⭐ OPTION 3: RAILWAY (SIMPLE)
   ✓ $5 free credit/month
   ✓ Auto-deploys on git push
   
   Steps:
   1. Connect GitHub repo to railway.app
   2. Add environment variables
   3. Done!

See DEPLOYMENT.md for detailed guides
